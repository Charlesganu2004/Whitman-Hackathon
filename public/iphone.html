The app, at iPhone size.

This frame runs the same bundle Expo serves to a phone. It is a browser simulation, so Screen Time shielding and the microphone behave as they do on web.

On a real iPhone

  1. Run npm run demo on the computer.
  2. Keep the phone on the same Wi-Fi and scan the QR code with the Camera app.
  3. Expo Go opens Unscroll and finds the server on its own.
